A derivative is a basic concept in calculus. The derivative of a function measures how fast the value of the function changes when its input changes. Geometrically, the derivative at a point is the slope of the tangent line to the graph of the function at that point. If the derivative is positive, the function is increasing, and if it is negative, the function is decreasing. Some simple rules make derivatives easy to compute. The derivative of a constant is zero. The derivative of x^n is n * x^(n-1), so the derivative of x^2 is 2x. Derivatives are used to find the minimum and maximum of a function, because at these points the derivative is equal to zero. In machine learning, derivatives are used in gradient descent to train neural networks.
